1. Брезенхем накапливает ошибку и по ней выбирает следующий пиксель, ЦДА - прибавляет приращения координат

2. error - накопленное отклонение от идеальной прямой. Если она становится достаточно большой, алгоритм дополнительно изменяет вторую координату.

3. Нужны, чтобы прямую можно было строить в любом направлении, а не только вправо вниз

4. Потому, что координаты следующего пикселя могут измениться одновременно

5.  (2, 5) -> (20, 5)
    (7, 2) -> (7, 20)
    (20, 8) -> (2, 3)
    (5, 20) -> (15, 2)
    (3, 2) -> (7, 25)
    (10, 10) -> (10, 10)

6. Не совпали. Например, на (2, 2) -> (20, 9)
