1. запустить index.html

2. Вершины через массив точек, ребра строятся алгоритмом Брезенхема

3. в массиве grid. 0 - пустая клетка, 1 - граница контура, 2 - закрашенная клетка   

4. 4-связность

5. Нижняя граница включается, верхняя - нет. Гоизонтальные ребра не добавляются как отдельное пересечение

6. Сравнение
- число обработанных элементов: для floodfill - больше числа закрашенных точек, scanline fill - число строк в многоугольнике
- время выполнения (для замкнутых многоугольников): floodfill в 2-3 раза быстрее, чем scanline fill 
- seed нужен для закраски произвольной области через floodfill
- геометрию многоугольника использует scanline fill
- если контур незамкнутый, floodfill закрасит всё, а scanline - останется в пределах отсутствующего ребра.
